# みえるエディタ

改行・タブ・空白が見えて、置換リストで一括置換できる、ブラウザで動くテキストエディターです。
[CodeMirror 6](https://codemirror.net/) をベースにしています。

**使う:** https://officenn.github.io/mieru-editor/ (Edge / Chrome 推奨)

## できること

- **記号の表示**: 改行 ↵ / タブ → / 半角空白 ・ / 全角空白(点線の枠)/ [EOF]
- **行内改行の強調**: ファイルの改行コード(CRLF など)と違う改行(Excel のセル内改行の LF など)を、行を分けずに赤い「↓LF」で表示。保存しても元の改行のまま。
- **検索・置換** (Ctrl+F / Ctrl+H): 正規表現・大文字小文字の区別・単語単位
- **置換リスト(一括置換)** (Ctrl+Shift+H)
  - `検索文字列 => 置換後文字列` を1行に1ルール(区切りはタブでも可、`#` で始まる行は無視)
  - 上から順番に置換し、「元に戻す」1回で全部取り消し
  - 「件数を確認」で、置換せずに件数だけ確認
  - `\n` `\t` が使える(`\n` はどの改行コードにも一致し、置換後はファイルの改行コードで入る)
  - 正規表現モードでは `$1` などの参照が使える
- **文字コード**: UTF-8(BOM あり/なし)・Shift_JIS・EUC-JP・UTF-16 LE を自動判定して開き、同じ文字コードで保存
- **上書き保存**(Edge / Chrome)、ドラッグ&ドロップで開く
- **アプリとしてインストール**: アドレスバーの「アプリをインストール」から。インストール後はエクスプローラーの「プログラムから開く」で .txt などを開ける

ファイルはすべてお使いの PC の中で処理され、どこにも送信されません。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173 で起動
npm run deploy   # ビルドして GitHub Pages(gh-pages ブランチ)に公開
```
